配置云同步（一次性 · 约 5 分钟）

云同步由免费的 Firebase 提供。只需在下面粘贴一次配置，以后打开本页就会自动连接。
📋 点我展开：一步步获取配置
  1. 打开 console.firebase.google.com（需 Google 账号，仅配置时用一次；国内直连需自备网络环境），点「添加项目」，名字随意（如 kenliao），创建时可关闭 Google Analytics。
  2. 进入项目，点首页中间的 Web 图标 </> 注册应用（昵称随意、不勾 Hosting），页面会给出一段 firebaseConfig 代码——整段复制备用。
  3. 左侧 构建 → Authentication → 开始使用 → 登录方式，启用 「电子邮件/密码」。
  4. 左侧 构建 → Firestore Database → 创建数据库，位置建议选 asia-southeast1 (Singapore)，以生产模式创建；切到「规则」标签，粘贴下面的规则并点「发布」：
    rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /users/{uid} { allow read, write: if request.auth != null && request.auth.uid == uid; } } }
  5. （可选：音频也上云）构建 → Storage → 开始使用，把规则换成：
    rules_version = '2'; service firebase.storage { match /b/{bucket}/o { match /audio/{uid}/{file} { allow read, write: if request.auth != null && request.auth.uid == uid; } } }
  6. 回到本页，把第 2 步复制的 firebaseConfig 整段粘贴到下面的框里 → 保存。
